🔀 Board Differences

Board specifications differ in assessment structure and emphasis. The core content is shared across boards; these are the genuine differences by board:

AQA: Written exam (3 hours, set text performance concepts and live production review, 40%); devising coursework with working notebook (30%); scripted performance (30%).
Edexcel: Devising coursework with portfolio (40%); text in performance group/monologue (20%); written exam on two set texts (40%).
OCR: Devising with portfolio (40%); performing scripted texts (20%); written paper exploring practitioners and performance texts (40%).
WJEC/Eduqas: Devising theatre (40%); text in performance (20%); written exam on set texts and live theatre review (40%).
