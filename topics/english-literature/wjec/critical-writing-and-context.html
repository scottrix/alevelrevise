Learning Objectives

  • Structure a critical essay
  • Use textual evidence

Key Points

  • Thesis-led paragraphs (PEEL)
  • Quotation analysis not quotation dumping
  • Context, author's intent, reader response

Example Question

How should an exam essay be structured?

Model Answer

Introduction stating a thesis, developed points with evidence, conclusion

Practice Questions
