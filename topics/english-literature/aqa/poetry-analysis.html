Board-Specific Note

Learning Objectives

  • Analyse language and imagery

Key Points

  • Themes and personal response
  • Compare across the anthology

Example Question

What effect does a metaphor create?

Model Answer

It creates a vivid comparison that deepens meaning

Practice Questions

  • Identify three poetic techniques in a given poem
  • Discuss how structure affects meaning
  • Compare two poems on a shared theme
