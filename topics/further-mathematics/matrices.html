Matrices and Linear Transformations

Year 1 / ASYear 2 / A-Level AQA, Edexcel, OCR, WJEC/Eduqas, CCEA

2x2 matrix multiplication, determinants, inverses, systems of equations and linear transformations with invariant points and lines - Edexcel 9FM0 Core Pure 1 revision with worked examples and mark-scheme logic.

🎯 Learning Objectives

  • Multiply conformable 2x2 matrices and interpret a matrix product as a composition of transformations, remembering AB ≠ BA (AO1) - Edexcel 9FM0/01 Core Pure 1; OCR MEI H645 Further Pure
  • Compute 2x2 determinants and use det(AB) = det A × det B, including the determinant as an area scale factor (AO1/AO2)
  • Find the inverse of a non-singular 2x2 matrix and use (AB)⁻¹ = B⁻¹A⁻¹ (AO1)
  • Solve systems of linear equations using matrix inverses and interpret singular cases as no solution or infinitely many solutions (AO2/AO3)
  • Write down matrices for rotations, reflections and enlargements and combine them in the correct order (AO1/AO2)
  • Find invariant points and invariant lines of a linear transformation, including lines of invariant points for reflections (AO2/AO3)

📋 Key Definitions and Core Concepts

Matrix: A rectangular array of numbers; a 2x2 matrix has the form [[a, b], [c, d]] with four entries.
Determinant: For M = [[a, b], [c, d]], det M = ad − bc. For a transformation, |det M| is the area scale factor; det M < 0 means orientation is reversed.
Singular matrix: A matrix with det M = 0: it has no inverse and its transformation collapses the plane onto a line or point.
Inverse matrix: M⁻¹ = (1/(ad − bc))[[d, −b], [−c, a]], defined only when det M ≠ 0, satisfying MM⁻¹ = M⁻¹M = I.
Identity matrix: I = [[1, 0], [0, 1]]: AI = IA = A for every 2x2 matrix A.
Linear transformation: A map of the plane sending each position vector x to Mx; straight lines map to straight lines and the origin maps to itself.
Invariant point: A point whose image is itself: Mx = x, equivalently (M − I)x = 0.
Invariant line: A line whose image under the transformation is the same line, though points on it may move along it; a line through the origin of gradient m satisfies M(1, m)ᵀ = k(1, m)ᵀ for some scalar k.

📌 Key Points

AB ≠ BA in general - matrix multiplication is not commutative.
det(AB) = det A × det B; |det M| is the area scale factor of the transformation.
A 2x2 matrix is invertible if and only if ad − bc ≠ 0.
Matrix of T followed by S is ST - the right-hand matrix acts first.
Rotations have det 1, reflections det −1, enlargement factor k has det k².
For a reflection, the mirror line is a line of invariant points; the perpendicular through O is an invariant line.

Matrix Arithmetic and Determinants

Products. For 2x2 matrices A = [[a, b], [c, d]] and B = [[e, f], [g, h]], the product AB has (i, j) entry given by multiplying row i of A into column j of B: AB = [[ae + bg, af + bh], [ce + dg, cf + dh]]. Multiplication is associative (A(BC) = (AB)C) and distributes over addition, but is not commutative: in general AB ≠ BA. The identity I = [[1, 0], [0, 1]] satisfies AI = IA = A. When a question gives a matrix equation such as A² = A (idempotent) or asks you to find matrix X satisfying AX = B, rearrange by multiplying by inverses on the correct side - left-multiplication and right-multiplication are different operations.

Worked example. A = [[2, 1], [5, 3]], B = [[0, 2], [3, 1]]: AB = [[2×0 + 1×3, 2×2 + 1×1], [5×0 + 3×3, 5×2 + 3×1]] = [[3, 5], [9, 13]]. Note BA = [[10, 6], [11, 6]] - different, as expected.

Determinants. det M = ad − bc, also written det(M) or |M|. Two properties carry most of the mark weight: det(AB) = det A × det B, and det(Aᵀ) = det A. In the example above, det A = 2×3 − 1×5 = 1 and det B = 0×1 − 2×3 = −6, so det(AB) = −6 - and indeed 3×13 − 5×9 = 39 − 45 = −6 ✓. Exam questions frequently ask you to verify this product rule.

Geometric meaning. For a transformation with matrix M, the image of a shape has area multiplied by |det M|, and det M < 0 signals that orientation is reversed (a flip). If det M = 0 the matrix is singular: the transformation squashes the whole plane onto a line (or a point), so distinct points share images and no inverse can exist. Singular matrices are the gateway to the system-of-equations cases in the next section.

Common trap

Entries go row-then-column: (row of A) × (column of B). Writing the transpose of the answer - columns of A times rows of B - is the single most common slip in matrix multiplication questions.

Inverses and Systems of Equations

The inverse formula. If det M = ad − bc ≠ 0, then M⁻¹ = (1/(ad − bc))[[d, −b], [−c, a]]: swap the leading diagonal, negate the other diagonal, divide by the determinant. Always check MM⁻¹ = I if asked to verify. The reversal rule (AB)⁻¹ = B⁻¹A⁻¹ holds whenever both factors are invertible - order flips, exactly as for transposes. A matrix is invertible if and only if it is non-singular.

Solving linear systems. The system 2x + 3y = 13, x − 2y = −4 is Mx = b with M = [[2, 3], [1, −2]] and b = (13, −4)ᵀ. det M = −4 − 3 = −7, so M⁻¹ = (1/7)[[2, 3], [1, −2]] and x = M⁻¹b = (1/7)[[2, 3], [1, −2]](13, −4)ᵀ = (1/7)(26 − 12, 13 + 8)ᵀ = (2, 3)ᵀ. Substituting back: 2×2 + 3×3 = 13 ✓. State the matrix equation, the determinant, the inverse and the solution - each step typically carries a mark.

Singular cases. When det M = 0 there is no unique solution, and the two possibilities are distinguished by consistency. The system x + 2y = 3, 2x + 4y = 7 has det [[1, 2], [2, 4]] = 0; doubling the first equation predicts 2x + 4y = 6, which contradicts 7, so the lines are parallel and distinct: no solution (inconsistent). But x + 2y = 3, 2x + 4y = 6 has the second equation a multiple of the first: the two equations describe the same line, so there are infinitely many solutions (a line of solutions). For 3x3 systems - which appear in OCR MEI Further Pure - the same trichotomy holds: unique (det ≠ 0), no common point, or a line/plane of common solutions.

Exam technique

Geometric interpretation marks are free if you learn the vocabulary: non-singular → unique intersection point; singular and consistent → lines coincide (infinitely many solutions); singular and inconsistent → parallel distinct lines (no solution). Quote the determinant first in every case.

Linear Transformations, Invariant Points and Invariant Lines

Matrices as maps. A 2x2 matrix M acts on position vectors: the point with position vector x maps to Mx. The unit square maps to a parallelogram whose sides are the columns of M - reading off the images of (1, 0) and (0, 1) is the fastest way to identify or construct a transformation. The standard matrices must be memorised:

TransformationMatrix
Rotation θ anticlockwise about O[[cos θ, −sin θ], [sin θ, cos θ]]
Reflection in line through O at angle α to x-axis[[cos 2α, sin 2α], [sin 2α, −cos 2α]]
Enlargement, centre O, factor k[[k, 0], [0, k]]
Stretch parallel to x-axis, factor k[[k, 0], [0, 1]]
Stretch parallel to y-axis, factor k[[1, 0], [0, k]]

Check the reflection formula with y = x (α = 45°): [[cos 90°, sin 90°], [sin 90°, −cos 90°]] = [[0, 1], [1, 0]] ✓. A negative enlargement factor k combines an enlargement with a 180° rotation, and has det k² > 0. Determinants classify the map: rotation det = 1 (area preserved), reflection det = −1 (area preserved, orientation reversed), enlargement det = k².

Composites. The matrix of transformation T followed by S is ST - the matrix acting first sits on the right. With Rθ denoting rotation by θ, note that RθRφ = R(θ+φ) but a reflection followed by a rotation is generally not a rotation: order matters both for the type of map and for its parameters.

Invariant points and lines. A point is invariant when Mx = x, i.e. (M − I)x = 0. An invariant line maps to itself as a set - points may slide along it. For a line through the origin with gradient m, require M(1, m)ᵀ = k(1, m)ᵀ. Worked example: M = [[3, −1], [−1, 3]]. Points on y = x: M(t, t)ᵀ = (2t, 2t)ᵀ - still on y = x, so y = x is an invariant line with scale factor 2 (only the origin is fixed). For general m: M(1, m)ᵀ = (3 − m, −1 + 3m)ᵀ = k(1, m)ᵀ, so k = 3 − m and −1 + 3m = m(3 − m), giving m² = 1: the invariant lines are y = x (scale 2) and y = −x (scale 4).

Structure to quote for common maps: for a reflection, the mirror line consists entirely of invariant points, and the line through O perpendicular to it is invariant with no fixed points (except O); for an enlargement with k ≠ 1, only O is an invariant point but every line through O is an invariant line.

Mark-scheme habit

Invariant line questions: take a general point (t, mt) or vector (1, m)ᵀ, apply M, demand the image lie on the same line, solve for m, then state the scale factor k by comparing M(1, m)ᵀ with (1, m)ᵀ. Distinguish 'invariant line' (set-wise) from 'line of invariant points' (point-wise) - examiners ask for exactly one of these.

💡 Worked Example

Exam-style: The transformation T is represented by the matrix M = [[3, −1], [−1, 3]]. (a) Find det M and M⁻¹. (3 marks) (b) Show that y = x is an invariant line of T and state the scale factor of T on this line. (3 marks) (c) Find the equation of the other invariant line of T. (3 marks)
Mark-scheme logic: (a) det M = 3×3 − (−1)(−1) = 9 − 1 = 8. M⁻¹ = (1/8)[[3, 1], [1, 3]]. (b) Take a general point (t, t) on y = x: M(t, t)ᵀ = (3t − t, −t + 3t)ᵀ = (2t, 2t)ᵀ, which also lies on y = x. So y = x maps to itself - it is an invariant line - and each point on it is scaled by factor 2 about O (so only the origin is an invariant point on it). (c) Require M(1, m)ᵀ = k(1, m)ᵀ: k = 3 − m and −1 + 3m = km = m(3 − m). Hence −1 + 3m = 3m − m², so m² = 1 and m = ±1. m = 1 gives y = x from (b); the other invariant line is y = −x. (On it, M(1, −1)ᵀ = (4, −4)ᵀ = 4(1, −1)ᵀ, scale factor 4.)

❓ Practice Questions & Mark Schemes

A = [[2, 1], [5, 3]] and B = [[0, 2], [3, 1]]. Find AB and det B. (4 marks)
Answer: AB = [[2×0 + 1×3, 2×2 + 1×1], [5×0 + 3×3, 5×2 + 3×1]] = [[3, 5], [9, 13]]. det B = 0×1 − 2×3 = −6. (Consistency check: det A = 1, so det(AB) = 1 × (−6) = −6, and 3×13 − 5×9 = −6 ✓.)
Find the inverse of M = [[3, −4], [1, 2]]. (3 marks)
Answer: det M = 3×2 − (−4)×1 = 6 + 4 = 10 ≠ 0, so M is non-singular. M⁻¹ = (1/10)[[2, 4], [−1, 3]]. (Check: M × (1/10)[[2, 4], [−1, 3]] = (1/10)[[6 − 4, 12 − 12], [2 + 2, 4 + 6]] = I ✓.)
Use a matrix method to solve the system 4x − 3y = 6, 2x + y = 7. (4 marks)
Answer: Write Mx = b with M = [[4, −3], [2, 1]], b = (6, 7)ᵀ. det M = 4 + 6 = 10, so M⁻¹ = (1/10)[[1, 3], [−2, 4]]. Then x = M⁻¹b = (1/10)(6 + 21, −12 + 28)ᵀ = (27/10, 8/5)ᵀ. Check: 4(2.7) − 3(1.6) = 10.8 − 4.8 = 6 ✓ and 2(2.7) + 1.6 = 7 ✓.
Write down the matrix representing a rotation of 60° anticlockwise about the origin, and find the image of the point (1, 0). (3 marks)
Answer: [[cos 60°, −sin 60°], [sin 60°, cos 60°]] = [[1/2, −√3/2], [√3/2, 1/2]]. The image of (1, 0) is the first column: (1/2, √3/2)ᵀ. (det = 1/4 + 3/4 = 1, as expected for a rotation.)
Find all invariant points of the transformation with matrix M = [[2, −1], [−1, 2]]. (4 marks)
Answer: Invariant points satisfy Mx = x, i.e. (M − I)x = 0 with M − I = [[1, −1], [−1, 1]]. Both rows give the same equation x − y = 0, so the solution set is the whole line y = x. Check: M(1, 1)ᵀ = (1, 1)ᵀ ✓. Every point on y = x is fixed, and there are no other invariant points.
