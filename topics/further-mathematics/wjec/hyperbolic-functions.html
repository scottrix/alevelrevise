Further Mathematics — Hyperbolic Functions

Exam board: WJEC  |  Back to subjects

Board-Specific Note

Pure plus applied options; check the specific pathway chosen.

Learning Objectives

  • Define sinh, cosh, tanh
  • Use their identities
  • Solve simple hyperbolic equations

Key Points

  • sinh x = (eˣ − e⁻ˣ)/2
  • cosh x = (eˣ + e⁻ˣ)/2
  • cosh²x − sinh²x = 1

Example Question

Evaluate cosh 0

Model Answer

cosh 0 = 1

Practice Questions

  • Show cosh²x − sinh²x = 1
  • Solve sinh x = 2
  • Evaluate tanh x for large x
