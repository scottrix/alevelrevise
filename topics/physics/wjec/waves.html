Physics — Waves

Exam board: WJEC  |  Back to subjects

Board-Specific Note

WJEC specification; mainly taken in Wales.

Learning Objectives

  • Describe wave properties
  • Use the wave equation
  • Apply the Doppler effect

Key Points

  • v = fλ
  • Longitudinal vs transverse
  • Doppler shift Δf = f·v/c

Example Question

Speed of a wave with f = 50 Hz and λ = 6 m?

Model Answer

v = 50 × 6 = 300 m/s

Practice Questions

  • Find λ if v=340 m/s and f=100 Hz
  • Is light transverse or longitudinal?
  • Describe how frequency changes for a moving source
