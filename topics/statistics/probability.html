Probability

Year 1 / ASYear 2 / A-Level Edexcel

Addition and multiplication rules, conditional probability, Venn and tree diagrams, independence and Bayes-style questions - Edexcel 9ST0 Topic 4 revised with exam-style questions and mark-scheme logic.

🎯 Learning Objectives

  • Apply the addition rule P(A union B) = P(A) + P(B) - P(A intersection B) and handle mutually exclusive and exhaustive events (AO1)
  • Read and construct Venn diagrams, translating written descriptions into region probabilities (AO1/AO2)
  • Calculate conditional probabilities from Venn diagrams, two-way tables and formulae (AO1)
  • Test whether two events are independent using P(A intersection B) = P(A)P(B) and interpret the result (AO2/AO3)
  • Complete tree diagrams with and without replacement and combine branch probabilities (AO1)
  • Answer Bayes-style given-that questions by reversing conditioning, with full working (AO2)

📋 Key Definitions and Core Concepts

Trial: A single performance of an experiment whose outcome is uncertain, e.g. one roll of a die.
Sample space: The set of all possible outcomes of an experiment; probabilities of all outcomes sum to 1.
Mutually exclusive: Events that cannot occur together: P(A intersection B) = 0, so P(A union B) = P(A) + P(B).
Exhaustive: Events that together cover the whole sample space: their union has probability 1.
Complement: The event A-prime (not A): P(A-prime) = 1 - P(A); used to convert at-least-one questions into one-minus-none.
Conditional probability: The probability of A given that B has occurred: P(A given B) = P(A intersection B) / P(B), for P(B) > 0.
Independence: Events A and B are independent if P(A intersection B) = P(A)P(B), equivalently P(A given B) = P(A) and P(B given A) = P(B).
Union: The event that A or B (or both) occurs; probability found with the addition rule.
Intersection: The event that both A and B occur; found with the multiplication rule or read from a Venn overlap.
Tree diagram: A diagram with branches whose first level carries unconditional probabilities and later levels carry conditional probabilities; multiply along branches and add between complete cases.

📌 Key Points

Addition rule: P(A union B) = P(A) + P(B) - P(A intersection B).
Conditional probability: P(A given B) = P(A intersection B) / P(B).
Independent means P(A intersection B) = P(A)P(B); mutually exclusive and independent are different ideas.
Multiply along tree branches; add between separate cases.
For P(A given B) where B came first in time, use Bayes reversal from the full tree.

The rules of probability and Venn diagrams

Probabilities live on a scale from 0 (impossible) to 1 (certain). Two structural facts do most of the early work: the complement, P(A-prime) = 1 - P(A), which converts questions such as at least one into one minus none; and the addition rule, P(A union B) = P(A) + P(B) - P(A intersection B), which requires the overlap to be subtracted because it is counted twice. If A and B are mutually exclusive the overlap is zero, so P(A union B) = P(A) + P(B). If events are exhaustive their union is the whole sample space, probability 1.

Venn diagrams turn wordy descriptions into region arithmetic. Draw the universal set, place the intersection first when it is known, and label every region including outside both circles. Learn the standard translations: only A means P(A) minus the overlap; A or B means the union; both means the intersection; neither means 1 minus the union; exactly one means the two non-overlapping parts of A and B added. Exam questions often describe frequencies (e.g. of 60 students, 35 study French...) - convert frequencies to probabilities only when the question asks, and otherwise work in counts and divide at the end.

A recurring mark-earning skill is finding the intersection from a conditional statement. If the question gives P(A given B) and P(B), then P(A intersection B) = P(A given B) x P(B); write that multiplication down explicitly - it is usually a dedicated method mark. Check any finished Venn by adding all region probabilities: the total must equal 1 (or the total frequency).

Two-way tables are the Venn diagram's twin and often quicker when data are given as counts. Rows and columns carry the marginal totals; each cell is an intersection. The same translations apply: only A is a single cell, neither is the grand total minus the row-plus-column sum. When a question gives a table and asks for a conditional probability, cover the rows outside the condition and read within the condition row or column - this physical restriction is what conditioning means, and writing the restricted fraction (e.g. 30 out of 55) before simplifying earns the method mark. Be ready to complete a partially given table first, using the fact that rows and columns sum to their totals.

Conditional probability and independence

Conditional probability restricts the sample space. Given that B has occurred, only outcomes inside B are possible, and A given B is the part of A inside B relative to B: P(A given B) = P(A intersection B) / P(B). Rearranged, this is the multiplication rule: P(A intersection B) = P(A given B) x P(B). In Venn or two-way table questions, conditioning physically means covering up the rest of the table: P(tea given female) is the tea column read only within the female row.

Independence is tested, not assumed. A and B are independent if and only if P(A intersection B) = P(A)P(B), equivalently P(A given B) = P(A) or P(B given A) = P(B) - knowing one event gives no information about the other. Exam questions supply numbers and expect you to compute both sides and state a conclusion in context: since P(A given B) = 0.545 but P(A) = 0.45, the events are not independent. Show both computations; the comparison alone is the answer.

The most reliable mark-earner in this topic is the distinction between mutually exclusive and independent. They are different conditions and cannot both hold for two non-zero probabilities: if A and B are exclusive then P(A given B) = 0, but independence would demand P(A given B) = P(A) > 0. Questions deliberately test whether you know that exclusive events are dependent, and that independence requires the multiplication rule to hold exactly.

A second family of questions asks you to find a conditional probability when the conditioning event has already happened in the data. Two classic setups: sampling without replacement, where the second draw is made from a reduced population and every branch probability must be updated; and given-that questions on two-way tables, where the denominator is the condition total rather than the grand total. In both, state what the sample space has become before calculating - the sentence for the second draw there are 7 counters remaining is itself a marking point. Finally, use complements inside conditional questions too: P(at least one red given the first was red) is 1 minus the probability of no red on the second draw, which is often a one-step calculation.

Tree diagrams and Bayes-style questions

A tree diagram is the safest machine for multi-step problems. The first level of branches carries unconditional probabilities; every later level carries conditional probabilities (the probability of the new outcome given the path taken so far). Multiply along a complete path to get the probability of that case; add between paths when a final event can occur in several ways. With replacement, the branch probabilities stay constant; without replacement, they change because the population shrinks - e.g. from a bag of 5 red and 3 blue counters, the second draw is from 7 counters, so P(red then blue) = (5/8)(3/7).

Bayes-style questions reverse the conditioning: the natural order of the tree gives P(path), but the question asks P(early event given late outcome). The method is fixed and full marks are available for writing it out: list the complete cases that make up the late outcome, add their probabilities to get the denominator, and divide the relevant case by that total. For a disease test with P(positive given disease) = 0.98 and P(positive given no disease) = 0.05 in a population where 2 percent have the disease: P(disease and positive) = 0.02 x 0.98 = 0.0196, P(no disease and positive) = 0.98 x 0.05 = 0.049, so P(positive) = 0.0686 and P(disease given positive) = 0.0196 / 0.0686 = 0.286.

Two habits make tree answers bulletproof. First, label every branch with its event and its probability, and annotate the end of each complete path with the product - examiners award method marks for structure even if arithmetic slips. Second, work in exact fractions where possible and round only the final answer to 3 significant figures; premature decimal rounding in the denominator is the most common cause of lost accuracy marks.

Choosing between a tree and a Venn is itself an exam skill. Use a tree when events happen in stages or when you need to reverse a conditional (Bayes); use a Venn or two-way table when a single collection is split by two characteristics and the question gives counts. If a question offers a choice, state yours in one sentence - the examiner cannot award structure marks for a method you did not show. And when a tree grows beyond two levels, do not multiply across everything blindly: identify which complete paths correspond to the event asked about, add only those, and check that the selected cases are exhaustive for that event.

Exam technique: avoiding the classic traps

This topic punishes rushed reading, so audit every answer against a fixed checklist. (i) Did you answer the conditioning the right way round? P(A given B) and P(B given A) are different numbers, and Bayes questions exist precisely because they differ. (ii) Did you use the addition rule when events overlap? Subtracting the intersection is a named method mark. (iii) Did you confuse mutually exclusive with independent? Test with the multiplication rule and say so in context. (iv) Did your tree keep conditional probabilities on later levels? Constant probabilities throughout the tree only apply with replacement.

Context sentences carry marks in 9ST0 probability. Conclusions should name the events: for example, the probability that a customer buys tea given that she is female is 0.545, which is higher than the overall probability of 0.45, so buying tea and gender are not independent. Numbers without the context nouns typically score zero for interpretation marks.

Finally, exploit the checking structure that examiners build in. All probabilities in a distribution or Venn must sum to 1 - verify before moving on. Complements convert hard questions into easy ones: P(at least one) = 1 - P(none) is almost always faster than adding the individual cases. And when a question chains conditionals (given that the first draw was red, find...), do not recompute from scratch: the condition has changed the sample space, so work within it.

A final word on presentation. Examiners reward answers that set out notation before calculation: define A, B, write the rule you will use, substitute, then answer. This costs seconds and secures method marks even when arithmetic slips later. In longer questions, keep each part of the working on its own line - merged working hides where the marks are. Practise writing the conclusion sentence for every interpretation mark: name the events, give the probability, and say what it means in the context of the question.

💡 Worked Example

Exam-style: A screening test for a medical condition behaves as follows: 2 percent of a population have the condition, P(positive result given the condition) = 0.98 and P(positive result given no condition) = 0.05. A person chosen at random from the population tests positive. Find the probability that the person has the condition, and interpret your answer in context. (6 marks)
Mark-scheme logic: Define C = has the condition, Pos = positive result. P(C) = 0.02 (or tree with first-level branches 0.02, 0.98) (1). P(C and Pos) = P(C) x P(Pos given C) = 0.02 x 0.98 = 0.0196 (1). P(C-prime and Pos) = 0.98 x 0.05 = 0.049 (1). Total: P(Pos) = 0.0196 + 0.049 = 0.0686 (1). Conditional: P(C given Pos) = 0.0196 / 0.0686 = 0.286 (3 sf) (1). Interpretation: despite the test being 98 percent accurate for people with the condition, because the condition is rare (2 percent), only about 28.6 percent of positive results are true positives - most positive results come from the large disease-free group (1). Method marks are for the tree or case listing; the final mark requires the context sentence about rarity.

❓ Practice Questions & Mark Schemes

Of 60 students, 35 study French (F), 24 study Spanish (S) and 12 study both. One student is chosen at random. Find (a) P(F union S), (b) P(neither subject), (c) P(F but not S). (4 marks)
Answer: (a) Addition rule: P(F union S) = (35 + 24 - 12)/60 = 47/60 (2 marks: method and answer). (b) Neither = 60 - 47 = 13, so 13/60 (1 mark). (c) F only = 35 - 12 = 23, so 23/60 (1 mark). Accept decimals to 3 sf; fractions are safer and avoid rounding issues.
Of 100 employees, 45 are male, of whom 30 prefer coffee and 15 prefer tea; 55 are female, of whom 25 prefer coffee and 30 prefer tea. One employee is chosen at random. (a) Find P(tea given female). (b) Find P(female given coffee). (c) Determine whether gender and drink preference are independent. (6 marks)
Answer: (a) Restrict to females: 30/55 = 6/11 = 0.545 (2 marks). (b) Restrict to coffee drinkers: 25/55 = 5/11 = 0.455 (2 marks). (c) P(tea) = 45/100 = 0.45; since P(tea given female) = 0.545 is not equal to P(tea) = 0.45, the events are not independent (equivalently P(tea and female) = 0.30 but P(tea)P(female) = 0.45 x 0.55 = 0.2475) (2 marks: both computations and the contextual conclusion).
A bag contains 5 red and 3 blue counters. Two counters are drawn at random, one after the other, with the first replaced before the second draw. Find the probability that the two counters are the same colour. (3 marks)
Answer: With replacement the probabilities are constant: P(both red) = (5/8) x (5/8) = 25/64; P(both blue) = (3/8) x (3/8) = 9/64 (1 mark each case). Same colour means red-red or blue-blue, which are mutually exclusive: 25/64 + 9/64 = 34/64 = 17/32 = 0.531 (1 mark).
The same bag (5 red, 3 blue) is used, but now the first counter is not replaced. Find the probability that the two counters are different colours. (3 marks)
Answer: Without replacement the second draw is from 7 counters: P(red then blue) = (5/8) x (3/7) = 15/56; P(blue then red) = (3/8) x (5/7) = 15/56 (1 mark per case). Different colours: 15/56 + 15/56 = 30/56 = 15/28 = 0.536 (1 mark). Note the change in branch probabilities is the key marking point.
In a factory, machine A produces 60 percent of items and 2 percent of its items are defective; machine B produces 40 percent of items and 5 percent of its items are defective. An item chosen at random is found to be defective. Find the probability that it came from machine B. (5 marks)
Answer: Cases making up defective: P(A and D) = 0.6 x 0.02 = 0.012 (1); P(B and D) = 0.4 x 0.05 = 0.020 (1). Total: P(D) = 0.012 + 0.020 = 0.032 (1). Reverse the conditioning: P(B given D) = 0.020 / 0.032 = 0.625 (2 marks: method and answer). Working via a labelled tree earns the same marks; state the conclusion in context if asked.
