Differentiation

Year 1 / ASYear 2 / A-Level All Boards (AQA, Edexcel, OCR, WJEC, CCEA) AQA

A-Level Mathematics revision: Differentiation. Learning objectives, key points, worked examples and practice questions across AQA, Edexcel, OCR, WJEC and CCEA.

📌 Key Points

Key Fact: Power rule: d/dx(xⁿ) = nxⁿ⁻¹ for all real n
Key Fact: Sum/difference: d/dx(f+/-g) = f' +/- g'
Key Fact: Product rule: d/dx(fg) = f'g + fg'
Key Fact: Quotient rule: d/dx(f/g) = (f'g - fg')/g^2
Key Fact: Chain rule: d/dx(f(g(x))) = f'(g(x))·g'(x)
Key Fact: Stationary points: f'(x) = 0. Max: f'' < 0; Min: f'' > 0; Inflection: f'' = 0 with sign change
Key Fact: Tangent: y - y₁ = f'(x₁)(x - x₁); Normal gradient = -1/f'(x₁)
Key Fact: Optimisation: find critical points, check endpoints, justify global max/min
Key Fact: Implicit: differentiate term-by-term w.r.t x, solve for dy/dx
Key Fact: Connected rates: dy/dt = dy/dx · dx/dt

🎯 Learning Objectives

  • Differentiate polynomials, rational and negative powers from first principles
  • Apply sum/difference, product, quotient and chain rules
  • Find gradients of tangents and normals to curves
  • Find and classify stationary points (maxima, minima, inflection)
  • Apply second derivative test for nature of stationary points
  • Solve optimisation problems (max/min area, volume, cost)
  • Use implicit differentiation for curves not in y = f(x) form
  • Understand connected rates of change

💡 Worked Example

Exam-Style Question

Question: Find the stationary points of y = x^3 - 3x^2 - 9x + 5 and determine their nature

Model Answer:

y' = 3x^2 - 6x - 9 = 3(x^2 - 2x - 3) = 3(x-3)(x+1) = 0 -> x = 3 or x = -1. y'' = 6x - 6. At x = 3: y'' = 12 > 0 -> minimum at (3, -22). At x = -1: y'' = -12 < 0 -> maximum at (-1, 10)

Q1: Differentiate y = x²√(2x + 1), simplifying your answer.

Show Model Answer

Answer: Product rule with u = x² and v = (2x + 1)^(1/2): du/dx = 2x, dv/dx = (2x + 1)^(-1/2) (chain rule). dy/dx = 2x(2x + 1)^(1/2) + x²(2x + 1)^(-1/2). Combining over a common denominator: dy/dx = [2x(2x + 1) + x²]/√(2x + 1) = (5x² + 2x)/√(2x + 1) = x(5x + 2)/√(2x + 1).

Q2: Find the equation of the tangent to the curve y = x³ - 2x + 1 at the point where x = -1.

Show Model Answer

Answer: dy/dx = 3x² - 2. At x = -1: gradient = 3(1) - 2 = 1. y-value: y = (-1)³ - 2(-1) + 1 = -1 + 2 + 1 = 2, so the point is (-1, 2). Tangent: y - 2 = 1(x - (-1)), so y = x + 3.

Q3: A curve is defined implicitly by x² + 2xy + 3y² = 6. Find the gradient of the curve at the point (1, 1).

Show Model Answer

Answer: Differentiate each term with respect to x, treating y as a function of x: 2x + 2y + 2x(dy/dx) + 6y(dy/dx) = 0. Collect dy/dx terms: (2x + 6y)(dy/dx) = -(2x + 2y), so dy/dx = -(x + y)/(x + 3y). At (1, 1): dy/dx = -(1 + 1)/(1 + 3) = -2/4 = -1/2.
