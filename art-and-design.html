🔀 Board Differences

Board specifications differ in assessment structure and emphasis. The core content is shared across boards; these are the genuine differences by board:

AQA: Coursework-based: Component 1 personal investigation with 1,000-3,000 word critical essay (60%); Component 2 externally set assignment with 15 hours supervised time (40%).
Edexcel: Component 1: personal investigation (60% of marks) including critical/contextual study; Component 2: externally set assignment with 15 hours supervised time (40%).
OCR: Portfolio unit (personal investigation, 60%) and externally set task with 15 hours supervised time (40%).
WJEC/Eduqas: Personal investigation portfolio (60%) including written critical study; externally set assignment (40%) with supervised time.
